# CognitiveOS Docs

Documentation for CognitiveOS, kept apart from the code repos.

| Folder | Contents |
|---|---|
| `engineering/` | Technical docs: architecture (actors, actor cells, scheduler, cloud/edge, final architecture), deployment and secrets, security policies (`security/`), ADRs (`adr/`), the API reference (`openapi.json`, `openapi.md`), drone simulation and voice demos, troubleshooting. Moved from `cognitive-os-core`'s `docs/` with their history. |
| `architecture/` | Architecture overview (PDF). |
| `papers/` | Papers. |
| `pitch/` | Pitch decks and one-pagers. |

The code lives in the CognitiveOS repos: `cognitive-os-core`,
`cognitive-os-control-plane`, `cognitive-os-actor`, `cognitive-os-domains`,
`cognitive-os-ui` and `cognitive-os-scripts`. Code comments cite these docs as
`cognitive-os-docs/engineering/<file>`.
